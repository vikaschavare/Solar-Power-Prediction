# Solar Power Prediction

## Project Title

Solar Power Prediction Using Machine Learning

## Description

Solar Power Prediction is an AI/ML mini project that predicts
solar power generation based on environmental conditions.

The project uses a Random Forest Regressor algorithm.

## Input Features

1. Temperature
2. Humidity
3. Solar Irradiance
4. Wind Speed
5. Atmospheric Pressure

## Output

The system predicts:

Solar Power Generation in kW

## Technologies Used

- Python

- NumPy
- Scikit-learn
- Random Forest Regressor
